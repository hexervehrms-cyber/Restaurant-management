## 🎓 Learning Resources

During the migration, the team will need to understand:

- Firestore document model vs SQL relations
- Firestore query patterns and limitations
- Firebase Auth and custom claims
- Firestore transactions and atomicity
- Real-time listeners and subscriptions
- Firestore security rules syntax
- Cost optimization for Firestore

Training sessions should be scheduled before Phase 1 begins.
